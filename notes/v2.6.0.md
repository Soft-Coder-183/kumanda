# Kumanda 2.6.0

## Fixed
- **A chat stuck on "Working…" and a Stop button that did nothing.** When you sent a prompt while Claude was still working,
  Claude Code could answer both in one turn, and Kumanda kept waiting for an end that never came (one chat showed "Working…
  20h"). A finished turn now ends everything sent before it, Stop always stops (even when Claude was already idle), and a
  chat that Claude Code itself reports as idle is shown as idle.

## Changed
- **Chats are freed for the desktop app sooner.** Kumanda now closes a chat's Claude process 3 minutes after it finishes
  (was 20). While the process is open, the Claude desktop app and VS Code see the chat as "open somewhere else" and cannot
  import or continue it. The next prompt from Kumanda opens it again.

## New
- **Close all Claude processes** in Settings closes every Claude process Kumanda started, at once.
- **Close the Claude process** in a chat's menu is now there in every state, not only when the chat is ready.
