# Kumanda 2.2.1

| | |
|---|---|
| Fixes | "Continue when the limit resets" waits only for a limit that is really in force |

## Fixes

1. **"Continue when the limit resets"** used the reset time of the next usage window even when no limit was in force, so after
   the limit was over it scheduled the prompt hours later (and sometimes said "Pick a time within the next 14 days"). Now:
   - the reset time is read from the limit message the button is under ("resets 4:20am", counted from when the message came);
   - if that time has passed, or no limit is in force, the prompt is sent right away;
   - "When the usage limit resets" in the **Later** menu is only offered while a limit is in force.
