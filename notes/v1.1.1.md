## Fixes

1. **The all-products page is split by chat too:** the page opened with the **Products** button at the top now splits every project
   by chat titles, like the project's own Products tab. Tapping a chat title takes you to that chat.
2. **It is clear where hidden products are:** a file you "Hide" is not deleted; it moves to the **Hidden by you** box under its chat
   and comes back with **Show**. Before, a hidden file vanished completely from the all-products page, and in the project's tab it
   was mixed into the same box as copies and old versions.
