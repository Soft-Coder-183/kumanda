# Kumanda 2.2.0

| | |
|---|---|
| New | "Now" list, search everything (Ctrl+K), Changes (git) tab, send later, saved prompts, drafts shared between devices |
| Improved | Copy buttons, earlier prompts with ↑/↓, Esc to stop, task list, context size, themes and text size |
| Fixes | Pasted screenshots stay in the draft; a "You've hit your limit" reply offers to continue when it resets |

## New

1. **Now:** the top of the sidebar lists every chat that is working, waiting for you, or finished while you were away, in all
   projects.
2. **Search everything:** `Ctrl+K` or **Search** in the sidebar finds projects, chats in every project and actions. In a
   project's Chats tab, filter the chats or press Enter to search inside the messages.
3. **Organise chats:** pin to the top, rename (the name shows in the terminal and VS Code too), archive. From the list's `⋯`
   or the chat's `⋯` menu.
4. **Changes tab:** the git branch, the changed files with their diffs and the recent commits of a project, read only.
5. **Send later:** **Later** in the composer sends the prompt at a time you pick or when the usage limit resets. Scheduled
   prompts show above the composer (Send now / Cancel) and in Settings.
6. **Saved prompts:** **Saved** inserts prompts you use often; edit the list in Settings. Shared by every device.
7. **Drafts follow you:** an unsent prompt is saved on the computer too, so you can start on the phone and finish on the
   computer.
8. **Share to Claude:** on Android, share text or a link from any app to the installed Kumanda.

## Improved

1. Copy buttons on replies and code blocks; **Edit again** on your own prompts.
2. ↑/↓ in an empty composer brings back your earlier prompts; `Esc` stops Claude; `Alt+N` new chat; `?` lists all shortcuts.
3. A **Latest** button when new messages arrive while you read further up.
4. Claude's task list shows above the composer; the status bar shows the context size and how long the work has been running.
5. Export a chat as Markdown; **Ask in chat** from a file writes `@file` into the prompt; the file view opens the file in VS Code.
6. Find a product on the Products page; a banner when the computer cannot be reached.
7. Settings: theme (system, light, dark) and text size per device.

## Fixes

1. Screenshots pasted into the prompt are kept with the draft when you leave the chat.
2. A "You've hit your limit · resets 4:20am" reply gets a **Continue when the limit resets** button; a failed turn gets **Retry**.
