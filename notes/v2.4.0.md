# Kumanda 2.4.0

## New
- **Watch chats running elsewhere.** A chat you continue in the terminal, VS Code or the Claude desktop app now updates live in
  Kumanda while you have it open: new prompts, replies and tool steps appear within a few seconds, without reopening the chat.

## Fixed
- **Missing prompts.** A prompt you wrote in the Claude desktop app or VS Code could be missing from the chat in Kumanda when
  Claude Code stored a system note in the same message (for example after resuming a chat, often with a pasted image). The
  prompt now shows, and chat titles and search see it too.
