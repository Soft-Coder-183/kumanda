# Kumanda 1.3.0

| | |
|---|---|
| New | `/btw` side questions are kept · the chat's products next to its title · effort and model show their real values · your prompt is not lost when you switch chats · "send now" with Ctrl+Enter · working time and finish time · usage percentage always visible · new project · choosing a project opens the latest chat · latest versions only |
| Fixes | The last things a closed chat wrote are visible |

## New

1. **Side questions (`/btw`):** write `/btw <question>` in a chat and Claude answers without interrupting the running work, in a
   copy of the chat and without using any tools. The chat itself is not affected. The question and answer sit in their own card in
   the chat; they are not lost if you reload the page or open it from another device.
2. **`/btw`s from the terminal:** the questions of side questions you asked in the terminal or in VS Code show up in their chat, where
   they were asked. Claude Code saves their answers nowhere, so the answers cannot be shown.
3. **The chat's products next to the title:** every chat's top bar has a **Products (n)** tab next to the title. It opens only the
   files that chat made; while the panel is open the composer stays visible, so you can look at products while writing. The
   project's Products tab stays as it was.
4. **Effort and model show what they are:** the selects no longer just say "Effort" / "Model"; with the default selected they show
   the real value from your Claude Code settings ("Effort: high (default)", "Model: Opus (default)"). The status bar below shows
   **the effort the last request really used** next to the model and the usage percentages; the select shows the next prompt's effort.
5. **Your prompt is not lost:** an unsent prompt is kept separately for every chat; it is still there when you go to another chat
   and come back.
6. **Send now with Ctrl+Enter:** while Claude works Enter queues the prompt; **Ctrl+Enter** (or the **Send now** button that shows
   while Claude works) interrupts the running work and sends the prompt right away, like in Claude Code.
7. **How long it worked, when it finished:** after every turn it says "Worked for 8m 0s · finished 21:52" (with the day if not
   today); in old chats too.
8. **The usage percentage is always visible:** the 5-hour and weekly usage only showed while Claude was working; now the last known
   value is kept and shows in every chat. Hovering shows the reset times; a window that has reset is not shown.
9. **New project:** **＋** in the sidebar creates a new project folder in the projects folder and goes to the first chat screen.
10. **Choosing a project opens the latest chat:** picking a project in the sidebar opens its latest chat directly; the back arrow
    goes to the project's chat list.
11. **Latest versions only:** old versions of a product (`app-1.0.apk` next to `app-1.1.apk`) and copies are no longer listed. The
    files stay on disk; Kumanda never deletes a file.
12. **Consecutive tools on one row:** commands and edits that come one after another gather on one collapsible row like
    "6 steps: Bash ×6"; tapping it shows them one by one, tapping those opens the command and its output.
13. **Longer history:** opening a chat loads many more messages; **Load older messages** at the top brings the whole chat.

## Fixes

14. **The last things a closed chat wrote:** opening a chat within 10 minutes after Claude's process closed from being idle did not
    show what was written in that process; now the whole chat shows.
