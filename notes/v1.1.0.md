# Kumanda 1.1.0

| | |
|---|---|
| New | Effort choice · products split by chat · "Products of this chat" |
| Sturdier | Runs in the background without being tied to any window · a password reset really logs out every device |
| Fixes | The setup script no longer says "did not start" to a running server · the selects fit on the phone |

## New

1. **Effort choice:** pick the thinking depth from the select under the chat (low, medium, high, xhigh, max or your Claude Code
   default). If you change it while the chat runs it applies from the next step. Low is faster and uses less quota, max thinks
   the deepest.
2. **Products split by chat:** in a project's Products tab every APK, EXE, HTML or video sits under the title of the chat that made
   it; tapping the title takes you to that chat. On the all-products page every card shows the chat's name too.
3. **Products of this chat:** the collapsible section at the top of the chat screen shows only the files made in that chat and
   refreshes by itself when Claude finishes.

## Sturdier

4. **Tied to no window:** Kumanda now starts fully independent in the background; it keeps running if you close the terminal,
   VS Code or Claude Code you started it from.
5. **When you forget the password** the password reset command works while Kumanda runs too: every logged-in device is really
   logged out and Kumanda restarts by itself. (Before, a running server kept the old devices logged in.)

## Fixes

6. The setup script no longer says "did not start" to a running server and opens the password screen by itself.
7. On the phone the mode, model and effort selects fit on the screen; no needless "Stop" button shows for a session that is not working.
