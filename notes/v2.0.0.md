# Kumanda 2.0.0

| | |
|---|---|
| Changed | Kumanda is now in English: the interface, the commands, the scripts and the docs |

## Changed

1. **Everything is in English:** the whole interface, messages and notifications, the setup scripts, the command line options,
   the README and the release notes.
2. **New script and option names.** If you used the old ones, use these now:

   | Before | Now |
   |---|---|
   | `.\kur.ps1` (`-Kaldir`) | `.\install.ps1` (`-Uninstall`) |
   | `.\uzak-kur.ps1` (`-Herkese`, `-Kapat`) | `.\remote-setup.ps1` (`-Public`, `-Off`) |
   | `node sunucu.mjs` | `node server.mjs` |
   | `--arkaplan`, `--durdur`, `--durum`, `--sifre-sifirla` | `--background`, `--stop`, `--status`, `--reset-password` |

3. **Your settings move by themselves.** On the first start the files in `%LOCALAPPDATA%\Kumanda` get their new names
   (`config.json`, `devices.json`, `push.json`, `server.log`, the `btw` folder): your password, logged-in devices, notifications and
   saved side questions stay. The old files are kept with a `.migrated` ending. Your browser keeps your drafts and layout too.

## Updating from 1.x

`git pull`, then `.\install.ps1`. It stops the running 1.x Kumanda, points the startup shortcut at the new server and starts it.
Reload the Kumanda page in your browsers afterwards.
