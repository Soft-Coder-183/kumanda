# Kumanda 2.1.0

| | |
|---|---|
| New | A VS Code button in the chat; "Chats" and "Back to chat" buttons for moving around |
| Improved | `/btw` side questions cost about half as much on long chats |
| Changed | The developer docs are now `BUILD.md`, `build.ps1` and `HANDOVER.md` |

## New

1. **Continue on the computer in VS Code.** The VS Code button in a chat's top bar opens the project in VS Code on the computer
   and the same chat in the Claude Code panel there. The chat has to be idle (not working) at that moment; Kumanda hands it over
   so two programs do not write to the same chat.
2. **Go to the project's other chats from a chat:** the **‹ Chats** button at the top left (on the computer too; before it was
   only on the phone).
3. **Back from a file to the chat:** when you open a file from the files panel, **‹ Back to chat** takes you back to the chat
   you were writing in, with your unsent prompt still there.

## Improved

1. **`/btw` reuses the chat's prompt cache.** A side question still sees the whole conversation (your prompts and Claude's
   replies) and still cannot use tools, but it no longer pays to write the whole conversation into the cache again. On a
   ~35k-token test chat a side question that reuses the cache cost $0.0056; one that rebuilds it cost $0.0107.

## Changed

1. For developers: `DERLE.md`, `derle.ps1` and `PROJE_DEVIR.md` are renamed to `BUILD.md`, `build.ps1` and `HANDOVER.md`.
