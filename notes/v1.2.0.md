# Kumanda 1.2.0

| | |
|---|---|
| New | A project file explorer and a highlighted file viewer · the sidebar narrows by dragging and opens/closes · bring back all hidden products with one tap |
| Fixes | Pressing "Show" no longer closes the "Hidden by you" box; you can bring products back one after another |

## New

1. **Project files (like the VS Code explorer):** the folder button in a project's top bar (`Ctrl+Shift+E` on the computer) opens
   the project folder as a tree. Folders open when tapped; a file shows with line numbers and syntax highlighting
   (JavaScript/TypeScript, JSON, HTML, CSS, Python, PowerShell, shell, the C family, SQL, YAML, INI and Markdown). Markdown files
   open with a preview, images show directly; **Open** opens the file in a separate tab, **Download** downloads it to your device.
   Files are only viewed; Kumanda never changes a file. Files starting with a dot (`.env`, `.git`…) are not shown.
2. **The sidebar at the width you want:** on the computer drag the right edge of the project list to widen or narrow it; narrowed
   enough it closes, dragging from the left edge of the screen brings it back. The **«** and **☰** buttons (or `Ctrl+B`) open and
   close it. The files panel resizes the same way. The widths are remembered on your device.
3. **Swiping on the phone:** inside a project, swiping right opens the project list from the left; swiping left or tapping outside
   closes it. The **☰** button does the same. The files panel is a drawer from the left on the phone too.
4. **Show all hidden:** in a project's Products tab and next to every project on the all-products page there is a button that brings
   all the products you hid back into the list at once. If the "Hidden by you" box has several products, a **Show all** shows up
   inside the box too.

## Fixes

5. **The "Hidden by you" box stays open:** when you bring a product back with **Show** (or hide a new one) the boxes you opened do
   not close and the page stays where you were reading, so you can bring products back one after another.
