# Kumanda 2.5.0

## New
- **See chats working elsewhere.** A chat that is working in the terminal, VS Code or the Claude desktop app now shows as
  running in Kumanda: the green dot next to the project, "running elsewhere" in the chat list and "Working in the Claude app"
  in the chat itself. Sending a prompt to such a chat from Kumanda asks first, because two Claudes on one chat can mix up its
  messages.

## Changed
- **The VS Code button opens only the project.** The button at the top of a chat opens the project folder in VS Code on the
  computer, without opening the chat in the Claude panel as well. To continue the chat itself in VS Code, use **Open this
  chat in VS Code** in the chat list's menu.
